# Java Arrays Practice – Set 2

A collection of 10 separate Java programs created for practicing arrays, loops, conditions, and two-dimensional matrices.

## Tasks

| № | Program | Description |
|---|---|---|
| 1 | `PrintEvenIndices` | Print elements at even indices |
| 2 | `SumPositiveNumbers` | Calculate the sum of positive numbers |
| 3 | `CountNumbersInRange` | Count numbers between 10 and 20 |
| 4 | `FindMinimumAndIndex` | Find the minimum value and its index |
| 5 | `AddFiveToArray` | Add 5 to every array element |
| 6 | `CompareWithFirst` | Count elements greater than the first element |
| 7 | `CopyEvenNumbers` | Copy even numbers into a second array |
| 8 | `WeeklyTemperatures` | Calculate average temperature and count days above average |
| 9 | `PrintTimetable` | Print a 2×3 matrix |
| 10 | `CountZerosInMatrix` | Count zeros in a 3×3 matrix |

## Technologies

- Java
- IntelliJ IDEA

## How to run

1. Open the project in IntelliJ IDEA.
2. Navigate to the `src` folder.
3. Open any Java class.
4. Run the `main` method.

Each program is independent and can be executed separately.
